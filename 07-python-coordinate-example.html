7  Jupyter에서 GEIDPipelineManager 직접 호출하기

GEIDPipelineManager의 역할을 이해한 뒤에는 Jupyter에서 아주 작은 bbox 하나를 직접 다운로드해보는 것이 좋다.

이 장에서는 main.py를 만들기 전에, Jupyter에서 GEIDPipelineManager를 직접 import해서 호출한다. 이렇게 하면 입력 geometry, target date, output 폴더가 core 모듈로 어떻게 전달되는지 눈으로 확인할 수 있다.

이 실험의 목적은 대량 처리가 아니라 다음 세 가지를 눈으로 확인하는 것이다.

  • GEID CLI의 left, right, top, bottom 인자가 Python에서 어떻게 만들어지는가
  • current imagery와 historical imagery 요청이 어떻게 다른가
  • 다운로드 결과가 실제 촬영일 기준 폴더로 어떻게 정리되는가

7.1 최소 bbox 예제

예제 bbox는 매우 좁은 영역으로 잡는다. 너무 넓은 bbox를 사용하면 다운로드 시간이 길어지고 패치 수가 많아져 학습용 예제로 적합하지 않다.

예시 좌표:

left longitude    2.2945
bottom latitude  48.8580
right longitude   2.2960
top latitude     48.8590
zoom             18

주의할 점은 좌표 순서다.

일반 bbox 표기는 보통 다음 순서를 쓴다.

left, bottom, right, top

하지만 GEID CLI는 다음 순서로 받는다.

left, right, top, bottom

따라서 main.py나 Jupyter 코드에서 bbox를 GEID CLI로 넘길 때 순서를 명확히 바꿔야 한다.

7.1.1 Jupyter 준비 셀

먼저 공통 설정을 만든다.

from pathlib import Path

base_dir = Path(r"E:\workspace\Other_nations")
geid_exe = r"C:\allmapsoft\geid\downloader.exe"

site_id = "manual_bbox"

bottom = 48.8580
right = 2.2960
top = 48.8590

7.1.2 current imagery

current imagery는 historical date 인자를 넣지 않는다.

GEID CLI로 직접 쓰면 다음과 같다.

"C:\allmapsoft\geid\downloader.exe" "manual_bbox_current.geid" 18 18 2.2945 2.2960 48.8590 48.8580 "E:\workspace\Other_nations\output\manual_examples\bbox"

Jupyter에서는 GEIDPipelineManager를 통해 같은 요청을 실행한다.

import geopandas as gpd
from shapely.geometry import box
from geid_pipeline import GEIDPipelineManager

roi_gdf = gpd.GeoDataFrame(
    {"site_id": [site_id]},
    geometry=[box(left, bottom, right, top)],
    crs="EPSG:4326",
)

pipeline = GEIDPipelineManager(
    base_dir=str(base_dir),
    geid_exe_path=geid_exe,
)

pipeline.download_roi(
    roi_gdf=roi_gdf,
    roi_name=site_id,
    output_sub_dir=output_sub_dir,
    target_dates=["current"],
    zoom=zoom,
)

7.1.3 historical imagery

historical imagery는 target date를 문자열로 넘긴다.

GEID CLI로 직접 쓰면 다음과 같다.

"C:\allmapsoft\geid\downloader.exe" "manual_bbox_2012-12-31.geid" 18 18 2.2945 2.2960 48.8590 48.8580 "E:\workspace\Other_nations\output\manual_examples\bbox" "2012-12-31"

Jupyter에서는 target_dates에 날짜 문자열을 넣는다.

pipeline.download_roi(
    roi_gdf=roi_gdf,
    roi_name=site_id,
    output_sub_dir=output_sub_dir,
    target_dates=["2012-12-31"],
    zoom=zoom,
)

7.1.4 Putney-Wandsworth full pipeline 예제

위의 파리 bbox는 좌표 순서와 GEID CLI 호출 방식을 이해하기 위한 최소 예제다.

우리 파이프라인의 핵심 기능을 보려면 조금 더 넓은 bbox에서 current와 historical target date를 함께 넣어보는 것이 좋다.

아래 bbox는 Putney, Hurlingham, Sands End, Wandsworth 일대를 포함하도록 잡은 예시다. 이 구간은 Google Earth 화면에서 같은 target 시점 안에서도 영상 경계가 뚜렷하게 보이는 사례로, 실제 촬영일 기준 분류를 설명하기에 적합하다.

left = -0.2350
bottom = 51.4500
right = -0.1700
top = 51.4825
zoom = 18

site_id = "manual_putney_wandsworth"
output_sub_dir = "manual_examples/putney_wandsworth_full_pipeline"

roi_gdf = gpd.GeoDataFrame(
    {"site_id": [site_id]},
    geometry=[box(left, bottom, right, top)],
    crs="EPSG:4326",
)

pipeline.download_roi(
    roi_gdf=roi_gdf,
    roi_name=site_id,
    output_sub_dir=output_sub_dir,
    target_dates=["current", "2014-02-15"],
    zoom=zoom,
)

이 실행은 다음 기능을 한 번에 보여준다.

  • 여러 target date 순회
  • GEID CLI 반복 호출
  • GEID log parsing
  • 실제 촬영일별 patch 분류
  • 동일한 실제 촬영일 폴더에 중복 patch 누적 방지
  • 날짜 폴더별 merge 가능 구조 생성

아래 Quarto Python chunk는 같은 작업을 문서 안에서 직접 수행한다. 이미 결과 폴더가 있으면 다시 다운로드하지 않고 기존 결과를 사용한다.

import os
import sys
from pathlib import Path

geid_env = Path(r"C:\Users\USER\.local\share\mamba\envs\geid")
os.environ["PATH"] = (
    str(geid_env)
    + os.pathsep
    + str(geid_env / "Library" / "bin")
    + os.pathsep
    + str(geid_env / "Scripts")
    + os.pathsep
    + os.environ.get("PATH", "")
)

other_nations = Path(r"E:\workspace\Other_nations")
if str(other_nations) not in sys.path:
    sys.path.insert(0, str(other_nations))

import geopandas as gpd
from shapely.geometry import box
from geid_pipeline import GEIDPipelineManager

base_dir = Path.cwd()
geid_exe = r"C:\allmapsoft\geid\downloader.exe"

site_id = "manual_putney_wandsworth"
output_sub_dir = "manual_examples/putney_wandsworth_full_pipeline"
zoom = 18

left = -0.2350
bottom = 51.4500
right = -0.1700
top = 51.4825

roi_gdf = gpd.GeoDataFrame(
    {"site_id": [site_id]},
    geometry=[box(left, bottom, right, top)],
    crs="EPSG:4326",
)

pipeline = GEIDPipelineManager(
    base_dir=str(base_dir),
    geid_exe_path=geid_exe,
    grid_chunk_size=16,
    fill_ratio_threshold=0.6,
)

patch_root = base_dir / "output" / output_sub_dir / f"patches_{site_id}"
output_root = base_dir / "output" / output_sub_dir

if not patch_root.exists() or not any(patch_root.iterdir()):
    pipeline.download_roi(
        roi_gdf=roi_gdf,
        roi_name=site_id,
        output_sub_dir=output_sub_dir,
        target_dates=["current", "2014-02-15"],
        zoom=zoom,
    )

for folder_path in sorted(p for p in patch_root.iterdir() if p.is_dir()):
    actual_date = folder_path.name
    output_tif = output_root / f"{site_id}_{actual_date}_Merged.tif"
    if output_tif.exists():
        continue

    image_array, meta = pipeline.merge_patches(
        target_folder=str(folder_path),
        output_filename=f"temp_{actual_date}",
    )
    pipeline.convert_to_geotiff(
        image_array=image_array,
        meta=meta,
        output_path=str(output_tif),
    )

print(f"patch root: {patch_root}")
print(f"actual-date folders: {len([p for p in patch_root.iterdir() if p.is_dir()])}")

7.2 결과 폴더 확인

실행 후에는 patches_{site_id} 아래에 실제 촬영일 폴더가 생긴다.

patch_root = base_dir / "output" / output_sub_dir / f"patches_{site_id}"

for path in sorted(patch_root.glob("*")):
    if path.is_dir():
        jpg_count = len(list(path.glob("*.jpg")))
        jgw_count = len(list(path.glob("*.jgw")))
        print(path.name, jpg_count, "jpg", jgw_count, "jgw")

예상 구조는 다음과 같다.

output/
└── manual_examples/
    └── bbox/
        └── patches_{site_id}/
            ├── Current_Default/
            │   ├── *.jpg
            │   ├── *.jgw
            │   └── manual_bbox_extraction_report.txt
            └── 2014-02-15 또는 실제 촬영일/
                ├── *.jpg
                ├── *.jgw
                └── manual_bbox_extraction_report.txt

historical imagery를 요청해도 실제 폴더명이 반드시 요청 날짜와 같지는 않을 수 있다. GEID 로그의 실제 촬영일을 기준으로 폴더가 만들어지기 때문이다.

7.3 날짜별 merge 확인

다운로드가 끝나면 날짜 폴더 하나를 골라 merge를 실행해볼 수 있다.

date_folders = [p for p in patch_root.iterdir() if p.is_dir()]
target_folder = date_folders[0]
actual_date = target_folder.name

image_array, meta = pipeline.merge_patches(
    target_folder=str(target_folder),
    output_filename=f"temp_{actual_date}",
)

output_tif = base_dir / "output" / output_sub_dir / f"{site_id}_{actual_date}_Merged.tif"
pipeline.convert_to_geotiff(
    image_array=image_array,
    meta=meta,
    output_path=str(output_tif),

아래 결과는 Putney-Wandsworth bbox에 대해 다음 target date 목록을 실행한 예시다.

target_dates = ["current", "2014-02-15"]

Quarto는 위 Python chunk로 예제 결과를 만들고, 아래 chunk에서 그 결과를 읽어 문서에 표시한다.

7.5 날짜별 patch를 동적 지도로 보기

날짜별로 분류된 patch를 동적 지도에 올리면 실제 촬영일 경계가 훨씬 직관적으로 보인다.

아래 chunk는 각 .jpg의 .jgw world file을 읽어 tile bounds를 계산하고, 실제 촬영일 폴더별로 Leaflet layer를 만든다.

import folium
from folium.raster_layers import ImageOverlay
from folium.plugins import Fullscreen
from IPython.display import HTML, display

def read_jgw_bounds(jgw_path, width=256, height=256):
    values = [float(v.strip()) for v in Path(jgw_path).read_text().splitlines()]
    x_scale, _, _, y_scale, top_left_x, top_left_y = values
    min_x = top_left_x
    max_y = top_left_y
    max_x = min_x + width * abs(x_scale)
    min_y = max_y - height * abs(y_scale)
    return [[min_y, min_x], [max_y, max_x]]

def requested_targets_for_date(date_dir):
    targets = []
    for report_path in sorted(date_dir.glob("*_extraction_report.txt")):
        for line in report_path.read_text(encoding="utf-8", errors="ignore").splitlines():
            if line.startswith("Requested Target"):
                targets.append(line.split(":", 1)[1].strip())
    return sorted(set(targets))

all_bounds = []
for jpg_path in sorted(patch_root.rglob("*.jpg")):
    jgw_path = jpg_path.with_suffix(".jgw")
    if jgw_path.exists():
        all_bounds.append(read_jgw_bounds(jgw_path))

min_lat = min(b[0][0] for b in all_bounds)
min_lon = min(b[0][1] for b in all_bounds)
max_lat = max(b[1][0] for b in all_bounds)
max_lon = max(b[1][1] for b in all_bounds)

m = folium.Map(
    location=[(min_lat + max_lat) / 2, (min_lon + max_lon) / 2],
    zoom_start=14,
    tiles="OpenStreetMap",
)

for date_dir in date_dirs:
    requested_targets = requested_targets_for_date(date_dir)
    target_label = ", ".join(requested_targets) if requested_targets else "unknown target"
    layer_name = f"{date_dir.name} (target: {target_label})"
    group = folium.FeatureGroup(name=layer_name, show=(date_dir.name == date_dirs[0].name))
    for jpg_path in sorted(date_dir.glob("*.jpg")):
        jgw_path = jpg_path.with_suffix(".jgw")
        if not jgw_path.exists():
            continue
        bounds = read_jgw_bounds(jgw_path)
        ImageOverlay(
            image=str(jpg_path),
            bounds=bounds,
            opacity=0.85,
            interactive=False,
            cross_origin=False,
        ).add_to(group)
    group.add_to(m)

folium.Rectangle(
    bounds=[[bottom, left], [top, right]],
    color="#ffcc00",
    weight=2,
    fill=False,
    tooltip="Requested bbox",
).add_to(m)

Fullscreen().add_to(m)
folium.LayerControl(collapsed=False).add_to(m)
m.fit_bounds([[min_lat, min_lon], [max_lat, max_lon]])

map_path = root / "putney_wandsworth_actual_date_layers.html"
m.save(map_path)
display(HTML(f'<iframe src="../{map_path.as_posix()}" width="100%" height="650" style="border:1px solid #ddd;"></iframe>'))

7.6 이 예제에서 main.py로 확장하기

위 코드는 main.py를 설계할 때 가장 작은 출발점이 된다.

처음에는 Jupyter에서 bbox 하나를 직접 넣어 실행하고, 이후 같은 값을 CLI flag로 옮긴다.

예:

python main.py --bbox -0.2350,51.4500,-0.1700,51.4825 --site-id manual_putney_wandsworth --zoom 18 --date 2014-02-15 --output-sub-dir manual_examples/putney_wandsworth_full_pipeline

current imagery는 다음처럼 실행할 수 있다.

python main.py --bbox -0.2350,51.4500,-0.1700,51.4825 --site-id manual_putney_wandsworth --zoom 18 --current --output-sub-dir manual_examples/putney_wandsworth_full_pipeline

이 흐름을 이해하면 GeoPackage나 CSV를 읽어 여러 site를 반복 실행하는 main.py로 확장하기 쉽다.
